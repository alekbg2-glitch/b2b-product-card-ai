# B2B Product Card AI Assistant (Контрольно-измерительные приборы)

> **Тестовое задание на позицию AI-разработчик.**  
> Прототип сервиса автоматизированной подготовки черновиков карточек товаров для B2B-интернет-магазина КИПиА и промышленной автоматики на базе LLM.

---

## 📌 1. Архитектура и принятые решения

### Архитектурный стек:
- **Backend:** Python 3.12, **FastAPI** (асинхронная обработка запросов, строгая валидация типов через **Pydantic v2**).
- **LLM Integration:** OpenAI-совместимый API (`httpx.AsyncClient`) с поддержкой любых провайдеров (OpenAI, Gemini, DeepSeek, локальные модели Ollama / vLLM).
- **Frontend / UI:** Минималистичный и чистый интерфейс на **Bootstrap 5.3 + Vanilla JS**, разделённый по стандартам (HTML-шаблон, внешний CSS `static/css/styles.css` и JS-скрипт `static/js/main.js`).
- **Форматы вывода:** Интерактивная карточка в браузере, Markdown (с кнопкой копирования в 1 клик) и чистый структурированный JSON.

### Ключевые инженерные решения и Guardrails:
1. **Защита от галлюцинаций (Zero-Hallucination Policy):**
   - В системном промпте и Pydantic-схеме закреплено жесткое правило: все технические характеристики (диапазоны, резьбы, класс точности, напряжения) извлекаются **исключительно** из входного JSON.
   - Если характеристика отсутствует или не указана, модель обязана вернуть статус `«данных нет»`.
2. **Точный контроль SEO-лимитов:**
   - **SEO Title:** строго до **70 символов** включительно.
   - **SEO Description:** профессиональный B2B-текст объёмом строго **800–1200 символов** без «воды». В интерфейсе и API выведены динамические счетчики знаков.
3. **Детектор недостающих данных для контент-менеджера:**
   - Модель анализирует входные данные с точки зрения инженера КИПиА. Если не указаны критичные параметры (например, степень защиты IP, межповерочный интервал, температура среды, габариты или резьба), сервис формирует блок замечаний `missing_data_warnings`, чтобы менеджер запросил уточнение у поставщика.
4. **Коммерческий блок для менеджеров по продажам:**
   - Целевая аудитория и отрасли применения, решаемые практические задачи на объекте и ключевые преимущества прибора.

## 🚀 2. Установка и запуск

### Быстрый запуск локально:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/b2b-product-card-ai.git
   cd b2b-product-card-ai
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # на Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   Скопируйте пример конфига:
   ```bash
   cp .env.example .env
   ```
   В файле `.env` укажите ключ API:
   ```ini
   LLM_API_KEY="ваш_api_ключ"
   LLM_BASE_URL="https://api.openai.com/v1"  # или любой OpenAI-совместимый эндпоинт
   LLM_MODEL="gpt-4o-mini"                   # или gemini-3.8-flash, deepseek-chat
   ```

4. **Запустите веб-сервис:**
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8090 --reload
   ```
   Откройте в браузере: `http://localhost:8090`

## 💻 3. Использование через CLI (консоль)

Сервис можно запускать без веб-интерфейса, пакетной обработкой через CLI:

```bash
# Генерация в Markdown
python3 cli.py -i samples/product_1_oven.json -o results/product_1_oven.md -f markdown

# Генерация в JSON
python3 cli.py -i samples/product_2_manotom.json -o results/product_2_manotom.json -f json
```

## 🧪 4. Автоматическое тестирование

Для запуска набора валидационных тестов:
```bash
python3 run_tests.py
```
Тесты проверяют:
- Корректность длины SEO Title (<= 70 символов).
- Корректность объёма SEO Description (800–1200 знаков).
- Ровно 3–5 поисковых запросов.
- Отсутствие галлюцинаций в структурированных характеристиках.
- Срабатывание детектора замечаний для контент-менеджера.

## 🛠 6. Ограничения решения и вектор дальнейших улучшений

### Текущие ограничения MVP:
- Сервис работает как stateless-инструмент без сохранения истории в базе данных (согласно ограничениям ТЗ).
- Пакетная генерация доступна через CLI, но в веб-интерфейсе реализована поштучная обработка.

### Возможные улучшения для Production:
1. **RAG / Интеграция с базой ГОСТ и технической документацией:**
   Подключение векторной базы знаний (Chroma/Qdrant) с PDF-паспортами приборов для автоматического извлечения чертежей, схем подключения и сертификатов.
2. **Интеграция с CMS и ERP (1С / Bitrix / OpenCart):**
   Прямая выгрузка сгенерированных карточек по REST API в каталог интернет-магазина со сменой статуса на *«Проверено контент-менеджером»*.
3. **Few-Shot Human-in-the-Loop обучение:**
   Возможность контент-менеджеру нажимать «Одобрить / Исправить», сохраняя исправления в датасет для автоматической калибровки промптов и fine-tuning.
